# ADR-0005: FSRS-6 spaced repetition (client-side)

## Status
Accepted

## Context
Boolean “practiced” flags do not schedule review. FSRS-6 (via ts-fsrs) beats SM-2 on open log-loss benchmarks for scheduling.

## Decision
- Vendor `ts-fsrs` as `learning-site/vendor/ts-fsrs.js` (UMD) — no npm to *run* the site.
- Persist card state in IndexedDB (`pw-fsrs` DB) with schema versioning.
- Grades: Again / Hard / Good / Easy.
- JSON export/import for Safari eviction risk.
- Sequence: shipped after content pipeline (Stage 2).

## Consequences
Author-time may later emit deck IDs from interview MD; v1 seeds from interview + essentials question IDs already on the page.
