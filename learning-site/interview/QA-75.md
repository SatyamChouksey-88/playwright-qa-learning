# QA 75 — curated two-week core

Spaced-repetition deck for a focused prep sprint (see Bank Demo drills + FSRS UI).

## Must-keep mechanism (≈25)
- Tier A: A1–A10, A12 (flake, locators, dialogs, download, tabs, storageState, webServer, await)
- Tier B: B flake triage, storageState wiring, route mocking, sharding, visual masking (sample 10)
- Essentials: smoke vs sanity, severity vs priority, Git PR flow, BDD outline (sample 5)

## Judgment / senior (≈25)
- Tier C: flake governance, hybrid API+UI, a11y strategy, cost of ownership (sample 12)
- Tier D: D10 AI governance, D31 impact analysis, D34 metrics for leadership (sample 8)
- New: D36–D40 agentic / LLM / MCP / QA75 meta

## Runnable pairing (≈25 cards mapped to practice)
- Bank Demo: login, locked persona, OTP+Clock, mock balance API, passkey flag
- Practice lab + mini-apps: iframe, OTP fill, clipboard
- Agents/MCP curriculum section + section MCQs

## Explicitly out of the 75
Duplicate “what is a locator” variants, pure trivia, and any card without a drill or war-story prompt.

Regenerate site data after editing tier markdown: `npm run build:content`.
