## Question

When must setup go through UI?

## Options

1. Never — always API
2. When testing the user journey under test includes those UI steps
3. Only on Fridays
4. When API does not exist — but journey tests need the path proven

## Correct answer

When testing the user journey under test includes those UI steps

## Why correct

Do not API-shortcut the behavior you are trying to prove.

## Why the others are wrong

- Option 1: Too absolute — UI path is sometimes the SUT.
- Option 3: Joke distractor.
- Option 4: Partial truth but B is the principle.
